# XAI para la Comprensión de Sesgos: Metodologías y herramientas

Repositorio del workshop presentado en el **V Congreso Internacional Tecnologías I+D+i para la Igualdad** (16/09/2025).

En los tres ejemplos se utiliza la librería <a href="https://github.com/Fuminides/ex-fuzzy" target="_blank">Ex-fuzzy</a> para explorar cómo los algoritmos explicativos basados en reglas borrosas pueden ayudar a detectar el sesgo de género en distintos contextos. El Ejemplo 3 también propone tres métodos para mitigar dicho sesgo.

## Ejemplos

- <a href="https://drive.google.com/file/d/14DYgHgXtphSJBYXsdOE_AgIj-g88oVJ-/view?usp=sharing" target="_blank">Ejemplo 1: Supervivencia al desastre del Titanic</a>
- <a href="https://drive.google.com/file/d/1SrCWcXrrF9PamKK9VFCTqiJstjFxNC0L/view?usp=sharing" target="_blank">Ejemplo 2: Supervivencia de pacientes con fallos cardiacos</a>
- <a href="https://drive.google.com/file/d/1h6BEMF4KKEpTDkqIU8Hk2v-Wqbae8x-K/view?usp=sharing" target="_blank">Ejemplo 3: Concesión de préstamos</a>
